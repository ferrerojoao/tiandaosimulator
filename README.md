# 天道模拟器

> 一个自动运转的修仙世界。你，是天道。

---

你俯瞰苍茫大地。十六个宗门林立，三十名修士往来。他们自己修炼、突破、战斗、结仇、陨落、留墓碑——你只需决定：干预谁，怎么干预。

## 你是天道意志

| 能力 | 消耗 | 效果 |
|------|------|------|
| 赐福 | 20 | 修炼速度 ×2.5，持续 20 季 |
| 诅咒 | 30 | 修炼速度 ×0.3 + 每季 5% 陨落 |
| 雷劫 | 50 | 降下天雷——画圈、15 秒、劈到死或扛过去 |
| 灵潮 | 30 | 指定位置灵气翻倍 20 季 |
| 秘境 | 60 | 传说级奇遇降临 |
| 指引 | 15 | 指定修士走向指定地点 |

天道值来自修士突破和陨落。世界越繁荣，你越强大。

## 世界自己运转

- **修炼体系**：6 个境界（炼气→筑基→金丹→元婴→化神→渡劫），突破需灵气、丹药、甚至罕见物品
- **灵根决定上限**：浊/清/玄/天，天灵根才能学遍所有功法
- **修士有性格**：嗜杀者见人就打，平和者不爱动手，贪婪者常逛坊市
- **天赋各不同**：天慧学得快、战神战力高、丹道善疗伤、探奇抢奇遇
- **关系网**：同宗抱团、仇人追杀、并肩作战结友谊
- **墓碑**：陨落修士留墓碑 20 年，路人会摸尸捡遗物

## 如何游玩

| 操作 | 作用 |
|------|------|
| 点击修士 | 右上角看简况 |
| 双击修士 | 看全属性、生涯大事、死因 |
| 右键空地 | 召唤灵潮/秘境/指引 |
| 右键修士 | 天道干预菜单 |
| 空格 | 暂停 |
| F11 | 全屏 |

游戏自动运行。你的乐趣在于**观察**和**介入**——推一把某个天才、劈死一个恶人、在宗门必争之地丢个灵潮看他们抢。

## 下载 & 运行

导出 .exe 双击即玩。Godot 4.6.3 引擎制作。完整设计见 `docs/master-design.md`。
