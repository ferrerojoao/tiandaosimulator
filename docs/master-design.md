## 一、游戏概述

### 1.1 一句话简介
一款 2D 像素风格的沙盒修仙世界模拟器——玩家扮演「天道意志」，俯瞰并干预一个自动运行的修仙世界，观察众多修士修炼、突破、争斗、合纵连横，最终成仙或陨落。

### 1.2 核心体验
- **观察与干预**：世界自动运行，修士自主行动；玩家可以选择性干预（赐予机缘、降下天劫等）
- **涌现叙事**：修士之间的互动自然产生故事线（结盟、背叛、复仇、传承）
- **沙盒自由**：没有固定剧情，每个世界的走向都不同

### 1.3 参考游戏
- 《修仙物语》——放置修仙体验
- 《长生劫》——随机事件和文字叙事
- 《RimWorld》——沙盒模拟与角色 AI
- 《Dwarf Fortress》——复杂世界生成

### 2.3 地形生成算法

采用多层噪声叠加：

```
Layer 1 - 高度图（FastNoiseLite · FBM · Simplex）
  frequency = 0.01 · octaves = 5
  → 决定陆地/水域/山脉基础形状

Layer 2 - 温度图（独立 FastNoiseLite）
  frequency = 0.008
  → 决定区域冷暖

Layer 3 - 湿度图（独立 FastNoiseLite）
  frequency = 0.012
  → 决定区域干湿

地形判定规则：
  高度 < 0.3                         → 深水/浅水
  高度 0.3-0.4 + 高湿度               → 沼泽
  高度 0.4-0.5 + 低湿度               → 沙地
  高度 0.4-0.6                        → 平原/草地
  高度 0.5-0.7 + 高湿度               → 森林
  高度 0.7-0.85                       → 山地
  高度 > 0.85                         → 高山（不可通行）

Layer 4 - 灵脉噪声（低频，独立 FastNoiseLite）
  噪声值 > 0.7 且 非水域/非高山        → 灵脉

宗门放置：
  在灵脉附近 3-8 tiles 处放置
  宗门间最小间距 ≥ 30 tiles
  共放置 6 个宗门

凡人聚落放置：
  在平原/草地上随机放置
  避开水域、高山、宗门驻地
  数量 10-15 个
```

### 2.4 灵气浓度

每个 tile 有一个灵气浓度值（0-100），影响修炼效率：

```
基础值   = 地形类型默认值
灵脉修正 = 距灵脉距离越近越高（衰减半径约 10 tiles）
最终灵气 = clamp(基础值 + 灵脉修正, 0, 100)
```

灵气浓度档位：
- 0：无灵气（水域、高山）
- 1-25：低（平原、草地、沙地）
- 26-50：中（森林、山地）
- 51-80：高（宗门驻地、灵脉附近）
- 81-100：极高（灵脉核心区）

### 2.5 时间系统

| 参数 | 值 |
|------|----|
| 基本单位 | 年（含春夏秋冬四季） |
| 内部计时单位 | tick（1 tick = 1 季 = 0.25 年） |
| 1x 速度下真实 1 分钟 | = 游戏 4 季（1 年） |
| 1x 速度下真实 1 秒 | ≈ 游戏 1/15 年（约 24 天） |

**各速度对照：**

| 速度 | 真实 1 秒 = 游戏时间 | 真实 1 分钟 = 游戏时间 |
|------|---------------------|----------------------|
| 暂停 | 停止 | 停止 |
| 1x | 1 季 / 4 分之 1 年 | 4 季（1 年） |
| 2x | 半年 | 2 年 |
| 5x | 1.25 年 | 5 年 |

> 1x 速度下，1 分钟 = 游戏 1 年；修士寿命 150-5000 年，玩家 2-80 分钟可看完一位修士一生。

**季节视觉效果（通过 TileMap modulate 实现）：**
- 春/夏：地图颜色偏绿
- 秋：森林/草地偏黄
- 冬：高地变白（雪），整体色调偏冷

| 练气期 | 初期 / 后期 | 150 年 | ★ |

| 金丹期 | 初期 / 后期 | 800 年 | ★★★ |
| 元婴期 | 初期 / 后期 | 2000 年 | ★★★★ |
| 化神期 | 初期 / 后期 | 5000 年 | ★★★★★ |
| 渡劫期 | 初期 / 后期 | 无限 | ★★★★★★ |
| 飞升 | — | 超脱 | — |

### 3.2 灵根体系

**品质等级（影响修炼速度基础值）：**

| 等级 | 名称 | 稀有度 | 特点 |
|------|------|--------|------|
| 1级 | 浊灵根 | 常见 | 修炼速度最低，无属性偏好 |
| 2级 | 清灵根 | 较常见 | 修炼速度中等，无属性偏好 |
| 3级 | 玄灵根 | 少见 | 修炼速度较高，无属性偏好 |
| 4级 | 天灵根 | 极稀有 | 修炼速度极高，无属性偏好 |
| 特殊 | 异灵根 | 传说 | 与某一种属性完美契合，该属性功法修炼速度大幅提升，其他属性速度降低 |

**灵根修炼速度倍率参考：**

| 灵根 | 倍率（基准为浊灵根 = 1.0） |
|------|--------------------------|
| 浊灵根 | 1.0× |
| 清灵根 | 1.5× |
| 玄灵根 | 2.5× |
| 天灵根 | 4.0× |
| 异灵根（匹配属性） | 6.0× |
| 异灵根（不匹配属性） | 0.6× |

### 3.3 修士属性

```
【基础属性】
  灵根品质   ← 决定修炼速度基础值
  根骨       ← 影响修炼速度（乘算）
  悟性       ← 影响突破成功概率
  气运       ← 影响机缘事件触发率
  心性       ← 影响走火入魔概率

【战斗属性】
  攻击力     ← 境界 + 功法 + 攻击法宝加成
  防御力     ← 境界 + 功法 + 防御法宝加成
  速度       ← 境界 + 身法类功法加成
  法力值     ← 境界 + 修炼类功法加成

【状态属性】
  年龄 / 寿命上限 / 当前修为 / 突破进度
  健康状态：正常 / 轻伤 / 重伤 / 走火入魔
```

### 3.4 性格特征

每位修士随机生成 1-3 个性格标签，影响行为倾向：

| 标签 | 行为影响 |
|------|----------|
| 贪婪 | 优先抢夺资源，倾向劫掠 |
| 仁慈 | 不主动攻击，愿意援助他人 |
| 好战 | 主动挑衅，战斗欲望高 |
| 和平 | 尽量避战，优先外交解决 |
| 孤僻 | 不加入宗门，倾向散修 |
| 热情 | 积极社交，快速建立关系 |
| 腹黑 | 表面友善暗中算计 |
| 坦率 | 行为直接，不善算计 |
| 随性 | 行为随机，难以预测 |
| 执念 | 某一目标的执着程度极高 |

### 3.5 修士 AI（Utility AI）

每个 tick，修士对所有可选行为评估效用值，选择效用最高的执行：

| 行为 | 效用提升条件 |
|------|-------------|
| 打坐修炼 | 修为不满 + 环境灵气尚可 |
| 闭关突破 | 修为满 + 条件评估通过 |
| 采集资源 | 物品匮乏 + 附近有资源 |
| 探索秘境 | 发现秘境入口 + 气运高 |
| 社交/结交 | 关系网络稀薄 + 性格外向 |
| 交易 | 需要物品 + 附近有交易场所 |
| 疗伤休息 | 受伤 / 走火入魔状态 |
| 游历 | 修为已满但条件不足 |
| 攻击他人 | 有仇恨 / 性格好战 + 胜算评估 |
| 加入宗门 | 散修 + 满足宗门招收条件 |

## 四、修炼与突破系统

### 4.1 功法

| 属性 | 可选值 |
|------|--------|
| 等级 | 凡品 / 黄品 / 玄品 / 地品 / 天品 |
| 类型 | 修炼类 / 战斗类 / 身法类 / 辅助类 |
| 属性 | 金 / 木 / 水 / 火 / 土 / 风 / 雷 / 冰 / 暗 / 光 |

**灵根与功法属性的匹配关系：**
- 1-4 级灵根：对所有属性无偏好，功法等级越高修炼速度越快
- 异灵根：只与绑定属性完美契合，修炼绑定属性功法速度 ×6，其他属性 ×0.6

**功法获取途径：**
- 宗门传承（加入宗门后可修炼宗门功法）
- 秘境探索（秘境奖励）
- 拍卖交易（灵石购买）
- 他人传授（关系足够深时）
- 天道残卷（解锁特殊功法）

### 4.2 修炼流程

```
1. 打坐修炼
   → 每 tick 修为增长值 = 基础修炼速度 × 灵根倍率 × 根骨系数
                         × 功法等级系数 × 环境灵气系数

2. 修为满（达到当前境界上限）
   → AI 评估是否满足突破条件
   → 条件不足：继续游历 / 积累资源
   → 条件足够：进入闭关突破
```

### 4.3 小境界突破（初期 → 后期）

- **唯一条件**：修为值满
- **流程**：修为满 → 闭关 → 经固定时间后突破判定
- **闭关时长**：受灵根品质影响（灵根越好越短）
- **存在失败可能，但不会致死**

**失败后果随境界递增：**

| 境界 | 小境界突破失败后果 |
|------|-----------------|
| 练气 / 筑基期 | 掉少量修为，重新开始 |
| 金丹期 | 掉修为 + 轻伤 |
| 元婴期 | 掉修为 + 重伤 |
| 化神 / 渡劫期 | 掉修为 + 重伤 + 走火入魔（不致死） |

### 4.4 大境界突破（跨境界）

**核心原则：**
- 唯一基础条件是「修为满」，任何突破都可以在修为满时发起
- 丹药、环境、资源等全部是**辅助条件**，能提升成功率
- 没有"必须携带某物品才能突破"的硬性限制

**辅助条件与加成：**

| 辅助条件 | 说明 |
|----------|------|
| 对应境界丹药 | 低境界效果显著，高境界效果递减（见下表） |
| 功法等级 | 等级越高加成越多 |
| 环境灵气 | 低境界无要求，高境界有门槛（见下表） |
| 灵髓 | 高级辅助，大幅提升成功率 |
| 天材地宝 | 各类特殊资源提供额外加成 |
| 宗门护法 | 同伴协助，降低失败受伤概率 |

**丹药效果递减：**

| 突破段 | 丹药提升幅度 |
|--------|------------|
| 练气 → 筑基 | +100% 成功率 |
| 筑基 → 金丹 | +60% 成功率 |
| 金丹 → 元婴 | +35% 成功率 |
| 元婴及以上 | +15% 成功率 |

**环境灵气门槛：**

| 突破段 | 环境要求 |
|--------|---------|
| 练气 → 筑基 | 无要求，任何地点均可 |
| 筑基 → 金丹 | 无要求 |
| 金丹 → 元婴 | 建议高灵气区域；普通区域成功率降低 |
| 元婴 → 化神 | **必须**在高灵气区域，否则无法突破 |
| 化神 → 渡劫 | **必须**在极品灵气区域（顶级灵脉/秘境） |
| 渡劫 → 飞升 | **必须**在极品灵气区域 + 特殊天地异象下 |

**各大境界突破的基础成功率与失败后果：**

| 突破段 | 基础成功率 | 失败后果 |
|--------|-----------|---------|
| 练气 → 筑基 | 较高 | 掉修为 |
| 筑基 → 金丹 | 中等 | 掉修为、受伤 |
| 金丹 → 元婴 | 中低 | 掉修为、重伤 |
| 元婴 → 化神 | 较低 | 重伤、走火入魔、可能陨落 |
| 化神 → 渡劫 | 低 | 走火入魔、高概率陨落 |
| 渡劫 → 飞升 | 极低 | 陨落 |

**突破成功率公式：**

```
基础概率 = 悟性系数 × 灵根系数 × 功法等级系数 × 环境灵气系数
最终概率 = 基础概率 × (1 + Σ辅助条件加成)

注：即使所有辅助条件全部满足，成功率也不为 100%（保留天道无常感）
AI 修士会在评估自身胜算足够时才尝试突破，条件不足则继续积累
```

## 五、宗门系统

### 5.1 宗门基本信息

- **宗门数量**：6 个，随地图生成时固定，修士不可自行创建
- **宗门等级**：小门派 → 中等宗门 → 大宗门（由弟子数量和最高境界决定）
- **宗门驻地**：固定在灵脉附近，拥有初始功法和资源

### 5.2 宗门运作

| 方面 | 说明 |
|------|------|
| 招收弟子 | 宗门 AI 主动向散修发出邀请，修士也可主动投帖 |
| 职位体系 | 宗主 → 长老 → 内门弟子 → 外门弟子 → 杂役 |
| 资源管理 | 宗门自动分配灵脉、功法、任务 |
| 宗门任务 | 采集资源、猎杀妖兽、攻打敌对势力 |
| 宗门资产 | 灵石、功法典籍、丹药、灵脉控制权 |

### 5.3 宗门外交

三种关系状态，宗门 AI 自动维护：

| 关系 | 行为 |
|------|------|
| 同盟 | 共享情报、协同守护、不互相攻击 |
| 中立 | 可交易，不主动冲突 |
| 敌对 | 争夺资源，发动宗门战争 |

| 攻击型 | 增加攻击力 | 飞剑、灵珠、法印 |
| 防御型 | 增加防御力 | 护心镜、灵甲、阵盘 |
| 特殊型 | 功能性效果 | 储物戒、隐匿符、传送阵盘 |

- **法宝品质**：凡品 / 黄品 / 玄品 / 地品 / 天品（与功法等级一致）
- **属性标签**：法宝可带功法属性，与修士灵根/功法匹配时额外加成
- **获取途径**：炼器系统制造 / 秘境获取

---

## 七、战斗系统

### 7.1 自动战斗

战斗由 AI 全程自动进行，玩家只能观看（或通过天道干预影响结果）。

**胜负计算因素：**
- 境界压制（高境界压低境界有大幅加成）
- 攻击 / 防御属性对比
- 功法属性克制关系
- 法宝加成
- 临场随机波动（±10%-20%）

### 7.2 战斗场景

| 类型 | 说明 |
|------|------|
| 单人斗法 | 修士之间 1v1 决斗 |
| 宗门战争 | 多方势力大规模冲突 |
| 渡劫战斗 | 修士对抗天劫（雷劫 / 心魔劫） |
| 妖兽猎杀 | 修士单独或组队猎杀妖兽 |

---

## 八、随机事件系统

### 8.1 事件分类

| 类型 | 示例事件 |
|------|---------|
| 机缘事件 | 发现秘境、获得传承、偶遇高人、天降灵宝 |
| 灾难事件 | 天劫降临、妖兽暴动、魔修入侵、灵脉枯竭 |
| 社交事件 | 结交道友、收徒传道、宗门冲突、情缘纠葛 |
| 世界事件 | 天地异象、仙人遗迹现世、上古封印松动 |

### 8.2 触发机制

- 基于修士「气运值」 + 世界时间共同触发
- 高气运修士更容易触发机缘事件
- 事件可能触发连锁反应（蝴蝶效应）
- 玩家可通过「天道干预」主动制造或阻止特定事件

---

## 九、天道意志（玩家）

### 9.1 玩家定位

玩家不扮演任何具体修士，而是这个世界的「天道意志」，拥有全图上帝视角。

### 9.2 天道能力

| 能力 | 说明 | 天机值消耗 |
|------|------|-----------|
| 天机洞察 | 查看任意修士详细属性 | 少量 |
| 赐予机缘 | 为指定修士触发一次机缘事件 | 中量 |
| 降下天劫 | 对指定修士降下雷劫 | 中量 |
| 改变天象 | 改变某区域灵气浓度或天气 | 中量 |
| 抹杀 / 复活 | 直接改变修士生死 | 大量 |

### 9.3 天机值机制

- 随时间缓慢自动回复
- 世界重大事件（大能飞升、势力覆灭）额外奖励天机值
- 过度干预 → 降低天机值恢复速度（防止滥用的平衡机制）

## 十三、美术规范

### 13.1 像素规格

| 素材类型 | 尺寸 |
|----------|------|
| 修士角色 | 16 × 16 或 32 × 32 像素 |
| 地图 Tile | 32 × 32 像素 |
| 宗门建筑 | 32×32 / 64×64 / 96×96（按规模） |
| 法宝图标 | 16 × 16 像素 |
| UI 图标 | 16 × 16 像素 |

### 13.2 色彩方案
- **主色调**：青绿（仙气）
- **辅助色**：金色（仙家气韵）、暗红（杀伐气）
- **特殊色**：紫色（灵脉/天道）、白金（飞升/大能）

### 13.3 各阶段美术策略
- **Phase 1-3（开发期）**：纯色块 + 简单几何图形占位
- **Phase 4-5（功能期）**：绘制基础像素角色和地形 Tile
- **Phase 6（打磨期）**：完善动画帧（行走、打坐、战斗、突破特效）

## 十四、已知风险

| 风险 | 说明 | 应对措施 |
|------|------|---------|
| 性能瓶颈 | 大量修士同时运行 Utility AI 可能导致卡顿 | 时间切片处理；限制同时活跃的修士数量上限 |
| 平衡性 | 境界修炼曲线难以第一次就调对 | 在修士数据中暴露参数，方便快速调参 |
| 复杂度膨胀 | 沙盒系统容易无限扩展 | 严格按 Phase 控制范围，每 Phase 做减法 |
| 内容量 | 随机事件/功法名称等文字内容需要积累 | Phase 5 开始集中补充，前期用占位文本 |
