# 修仙世界模拟器 - 游戏策划文档

> 版本：v0.6  
> 日期：2026-03-23  
> 引擎：Godot 4.x  
> 视觉风格：2D 像素风  
> 项目定位：个人练手/学习项目  

---

## 一、游戏概述

### 1.1 一句话简介
一款 2D 像素风格的沙盒修仙世界模拟器——玩家扮演天道意志，管理一个修仙世界中众多修士的命运，观察他们修炼、突破、争斗、合纵连横，最终成仙或陨落。

### 1.2 核心体验
- **观察与干预**：世界自动运行，修士自主行动；玩家可以选择性干预（赐予机缘、降下天劫等）
- **涌现叙事**：修士之间的互动产生自然的故事线（结盟、背叛、复仇、传承）
- **沙盒自由**：没有固定剧情线，每个世界的走向都不同

### 1.3 参考游戏
- 《修仙物语》——放置修仙体验
- 《长生劫》——随机事件和文字叙事
- 《RimWorld》——沙盒模拟与角色 AI
- 《Dwarf Fortress》——复杂世界生成

## 二、核心系统设计

### 2.1 世界系统

#### 2.1.1 世界生成
- 程序化生成 2D 像素地图（类似 Roguelike 地图）
- 地形类型：平原、山脉、河流、森林、沼泽、灵脉、禁地
- 区域划分：凡人聚落、修仙城市、宗门驻地、秘境入口、荒野
- 灵气浓度：不同区域灵气浓度不同，影响修炼效率

#### 2.1.2 时间系统
- 世界时间以「年」为单位推进
- 修士有年龄概念，凡人寿命 ~80 岁，修士寿命随境界提升大幅增长
- 时间流速可调节（暂停 / 1x / 2x / 5x）

### 2.2 修士系统（核心）

#### 2.2.1 境界体系
| 大境界 | 小境界 | 寿命上限 | 修炼难度 |
|--------|--------|----------|----------|
| 练气期 | 初期 / 后期 | 150 年 | ★ |
| 筑基期 | 初期 / 后期 | 300 年 | ★★ |
| 金丹期 | 初期 / 后期 | 800 年 | ★★★ |
| 元婴期 | 初期 / 后期 | 2000 年 | ★★★★ |
| 化神期 | 初期 / 后期 | 5000 年 | ★★★★★ |
| 渡劫期 | 初期 / 后期 | 无限 | ★★★★★★ |
| 飞升 | — | 超脱 | — |

#### 2.2.2 修士属性
```
基础属性：
  - 灵根品质：
    - 浊灵根（1级）：资质平庸，修炼速度最低
    - 清灵根（2级）：资质尚可，修炼速度中等
    - 玄灵根（3级）：资质出众，修炼速度较高
    - 天灵根（4级）：万中无一，修炼速度极高
    - 异灵根（特殊）：与某一种功法属性完美契合，修炼该属性功法时速度额外加成
      - 例：雷异灵根 + 雷属性功法 → 修炼速度大幅提升，其他属性功法速度降低
  - 根骨（影响修炼速度）
  - 悟性（影响突破概率）
  - 气运（影响机缘触发率）
  - 心性（影响走火入魔概率）

战斗属性：
  - 攻击力 / 防御力 / 速度 / 法力值
  - 功法属性加成（根据修炼功法的五行属性浮动）

状态属性：
  - 年龄 / 寿命 / 修为值 / 突破进度
  - 健康状态：正常 / 受伤 / 重伤 / 走火入魔
```

#### 2.2.3 修士 AI（行为决策）
采用 **效用评估（Utility AI）** 模型：
- 每个修士在每个时间周期评估可选行为，选择效用最高的执行
- 可选行为包括：修炼、探索、收集资源、交易、社交、突破、闭关、游历、结丹/结婴
- AI 会根据自身状态和环境动态调整优先级
  - 例：修为接近突破 → 优先准备突破材料
  - 例：健康受损 → 优先疗伤
  - 例：发现秘境 → 优先探索

#### 2.2.4 性格特征
每个修士拥有随机生成的性格标签，影响行为倾向：
- 贪婪 / 仁慈 / 好战 / 和平 / 孤僻 / 热情 / 腹黑 / 坦率 / 随性 / 执念
- 性格影响：社交偏好、战斗决策、资源分配、善恶倾向

### 2.3 宗门系统

#### 2.3.1 宗门运作
- 宗门在世界生成时由地图生成系统预先设定，拥有固定的驻地和初始资源
- 修士不可自行创建宗门，只能选择加入已有宗门或作为散修独立修炼
- 宗门有等级：散修 → 小门派 → 中等宗门 → 大宗门
- 宗门资源：灵石、功法、丹药、灵脉、弟子

#### 2.3.2 宗门管理
- 宗门自动运转：招收弟子、分配任务、管理资源、攻防战略
- 宗门内职位：宗主 → 长老 → 内门弟子 → 外门弟子 → 杂役
- 宗门间关系：同盟 / 中立 / 敌对

### 2.4 修炼系统

#### 2.4.1 功法
- 功法等级：凡品 / 黄品 / 玄品 / 地品 / 天品
- 功法类型：修炼类 / 战斗类 / 身法类 / 辅助类
- 功法属性：金 / 木 / 水 / 火 / 土 / 风 / 雷 / 冰 / 暗 / 光
  - 1-4级灵根：不同品质灵根对所有属性功法的基础加成比例不同，无属性偏好
  - 异灵根（特殊）：与某一种属性完美匹配，该属性修炼速度大幅提升，其他属性速度降低
- 功法获取：宗门传承 / 秘境探索 / 拍卖交易 / 他人传授
- 功法品质影响修炼速度和战斗能力上限

#### 2.4.2 修炼过程
```
修炼流程：
  1. 打坐修炼 → 修为值缓慢增长（受灵根、功法、环境灵气影响）
  2. 修为满 → AI 评估是否尝试突破
  3. 进入突破流程（分为小境界突破和大境界突破，见 2.4.3）
```

#### 2.4.3 突破机制

**小境界突破（初期 → 后期）**
- 条件：修为值达到当前小境界上限
- 流程：修为满后进入闭关状态，经过一段固定时间后进行突破判定
- 存在失败可能，但不会致死
- 失败后果随境界递增：
  - 练气/筑基期：仅掉少量修为
  - 金丹期：掉修为 + 轻伤
  - 元婴期：掉修为 + 重伤
  - 化神/渡劫期：掉修为 + 重伤 + 走火入魔（不致死）
- 闭关时长受灵根品质影响（灵根越好闭关越短）

**大境界突破（跨境界）**

大境界突破难度随境界递增。所有突破的唯一基础条件都是「修为满」，其余皆为辅助条件。丹药、功法、环境等都会提升成功率，但没有任何突破需要特定物品才能发起。

辅助条件分类：
| 辅助条件 | 说明 |
|----------|------|
| 丹药 | 对应境界的辅助丹药，低境界时效果显著，高境界效果递减 |
| 功法等级 | 功法等级越高加成越多 |
| 环境灵气 | 中低境界时无明显要求，高境界突破必须在高灵气区域进行 |
| 灵髓 | 高级辅助资源，大幅提升成功率 |
| 天材地宝 | 各类特殊辅助资源 |
| 宗门护法 | 同伴/宗门成员协助护法，降低失败受伤概率 |

**丹药效果递减规则：**
```
低境界（练气→筑基）：对应丹药可提升 100% 成功率
中境界（筑基→金丹）：对应丹药可提升 60% 成功率
中高境界（金丹→元婴）：对应丹药可提升 35% 成功率
高境界（元婴及以上）：对应丹药可提升 15% 成功率
```

**环境灵气要求：**
```
练气→筑基：无环境要求（任何地点皆可）
筑基→金丹：无环境要求
金丹→元婴：建议在高灵气区域（灵脉/宗门灵池等），普通区域成功率降低
元婴→化神：必须在高灵气区域，否则无法突破
化神→渡劫：必须在极品灵气区域（顶级灵脉/秘境等）
渡劫→飞升：必须在极品灵气区域 + 特殊天地异象下
```

**大境界突破失败后果：**

| 大境界突破 | 基础成功率 | 失败后果 |
|------------|-----------|----------|
| 练气→筑基 | 较高 | 掉修为 |
| 筑基→金丹 | 中等 | 掉修为、受伤 |
| 金丹→元婴 | 中低 | 掉修为、重伤 |
| 元婴→化神 | 较低 | 重伤、走火入魔、可能陨落 |
| 化神→渡劫 | 低 | 走火入魔、高概率陨落 |
| 渡劫→飞升 | 极低 | 陨落 |

**突破成功率计算：**
```
基础概率 = 悟性 × 灵根系数 × 功法等级系数 × 环境系数
最终概率 = 基础概率 × (1 + 辅助条件加成总和)
```
- 辅助条件每满足一项，概率按固定比例提升
- 高境界突破中，即使所有辅助条件都满足，成功率也不为 100%（保留天道无常感）
- AI 修士会在评估自身条件足够时才尝试突破，条件不足则继续积累

### 2.5 物品与资源

#### 2.5.1 资源类型
| 资源 | 用途 | 获取方式 |
|------|------|----------|
| 灵石 | 通用货币 | 矿脉采集 / 任务奖励 / 交易 |
| 灵草 | 炼丹材料 | 山林采集 / 灵田种植 |
| 矿石 | 炼器材料 | 矿脉采集 |
| 兽核 | 炼丹/炼器材料 | 击杀妖兽 |
| 天材地宝（特殊资源） | 各类特殊用途（见下表） | 秘境 / 世界事件 / 高阶妖兽 / 天机值兑换 |

**天材地宝分类：**
| 名称 | 用途 | 获取途径 |
|------|------|----------|
| 灵髓 | 延寿续命，突破时大幅提升成功率 | 高阶妖兽 / 秘境宝箱 / 世界事件 |
| 魂晶 | 复活陨落修士、修复受损神魂 | 上古遗迹 / 渡劫期修士残魂 / 天道赐予 |
| 天道残卷 | 领悟新功法、突破功法等级上限 | 秘境深处 / 天机值兑换 |
| 聚灵珠 | 临时大幅提升区域灵气浓度 | 世界事件 / 大宗门宝库 |
| 破界石 | 开启秘境入口 | 世界事件 / 天机值兑换 |
| … | 后续可扩展 | — |

#### 2.5.2 丹药系统
- 丹药类型：疗伤丹 / 培元丹 / 筑基丹 / 结丹丹 / 境界辅助丹
- 需要修士具备「炼丹」技能才能炼制
- 丹药品质：下品 / 中品 / 上品 / 极品

#### 2.5.3 法宝系统
- 法宝分为三类（按用途）：
  - **攻击型**：增加攻击力（如飞剑、灵珠、法印）
  - **防御型**：增加防御力（如护心镜、灵甲、阵盘）
  - **特殊型**：功能性效果（如储物戒、隐匿符、传送阵盘）
- 法宝品质：凡品 / 黄品 / 玄品 / 地品 / 天品（与功法等级一致）
- 法宝可带有属性标签，与功法/灵根属性产生匹配加成
- 可通过炼器系统制造或秘境获取

### 2.6 战斗系统

#### 2.6.1 自动战斗
- 战斗由 AI 自动进行，玩家观察
- 战斗结果由双方属性、功法、法宝综合计算
- 考虑因素：境界压制、属性克制、法宝强度、临场发挥（随机波动）

#### 2.6.2 战斗场景
- 单人斗法：修士之间的 1v1 决斗
- 宗门战争：多方势力的大规模冲突
- 渡劫战斗：修士对抗天劫（雷劫 / 心魔劫）
- 妖兽猎杀：修士组队或单独猎杀妖兽

### 2.7 随机事件系统

#### 2.7.1 事件类型
- **机缘事件**：发现秘境、获得传承、偶遇高人、天降灵宝
- **灾难事件**：天劫降临、妖兽暴动、魔修入侵、灵脉枯竭
- **社交事件**：结交道友、收徒传道、宗门冲突、情缘纠葛
- **世界事件**：天地异象、仙人遗迹现世、上古封印松动

#### 2.7.2 事件触发机制
- 基于修士气运值和世界时间触发
- 高气运修士更容易触发机缘
- 事件可能产生连锁反应（蝴蝶效应）

## 三、玩家角色——天道意志

### 3.1 玩家定位
玩家不是某个具体修士，而是这个世界中的「天道意志」，拥有俯瞰全图的上帝视角。

### 3.2 玩家能力
| 能力 | 说明 | 代价 |
|------|------|------|
| 天机洞察 | 查看任意修士的详细属性和未来预测 | 消耗天机值 |
| 赐予机缘 | 为指定修士制造一次机遇 | 消耗天机值 |
| 降下天劫 | 对指定修士降下雷劫 | 消耗天机值 |
| 改变天象 | 改变某区域的灵气浓度或天气 | 消耗天机值 |
| 抹杀/复活 | 直接改变修士生死 | 消耗大量天机值 |

### 3.3 天机值
- 天机值随时间缓慢恢复
- 世界中的重大事件（大能飞升、势力覆灭等）会奖励天机值
- 制造过多干预会降低天机值恢复速度（避免过度干预的平衡机制）

## 五、技术架构（Godot 4.x）

### 5.1 场景结构
```
Game (Main)
├── WorldMap          # 世界地图场景
│   ├── TileMapLayer  # 地形层（使用 TileMap）
│   ├── Entities      # 修士/妖兽实体层
│   ├── Buildings     # 宗门/建筑层
│   └── Effects       # 特效层（战斗特效、天劫特效等）
├── UI                # UI 层
│   ├── TopBar        # 顶部信息栏（时间、天机值）
│   ├── SidePanel     # 侧边详情面板
│   ├── EventLog      # 事件日志
│   ├── TimeControl   # 时间控制按钮
│   └── MenuSystem    # 菜单系统
└── Systems           # 系统管理（不可见节点）
    ├── WorldManager      # 世界管理
    ├── CultivatorManager # 修士管理
    ├── SectManager       # 宗门管理
    ├── EventSystem       # 事件系统
    ├── CombatSystem      # 战斗系统
    ├── ItemManager       # 物品管理
    └── TimeManager       # 时间管理
```

### 5.2 数据架构
```
Data Models (Resource / Custom Class):
├── Cultivator           # 修士数据
│   ├── 基础属性
│   ├── 修炼进度
│   ├── 物品栏
│   ├── 关系列表
│   └── 历史记录
├── Sect                 # 宗门数据
│   ├── 宗门信息
│   ├── 成员列表
│   ├── 资源库存
│   └── 外交关系
├── World                # 世界数据
│   ├── 地图数据
│   ├── 区域列表
│   ├── 灵脉分布
│   └── 全局状态
└── Item                 # 物品/丹药/法宝数据
```

### 5.3 关键技术点
- **地图生成**：使用 Godot 的 `TileMap` + 噪声算法（`FastNoiseLite`）生成地形
- **AI 系统**：Utility AI，每个修士每 tick 评估行为优先级
- **事件系统**：基于权重的随机事件池 + 条件触发器
- **存档系统**：序列化为 JSON 文件
- **性能优化**：只更新视口内可见修士的动画，屏幕外的修士只更新数据

- [ ] Godot 项目初始化，搭建场景结构

## 七、美术需求

### 7.1 像素风格规格
- 角色尺寸：16×16 或 32×32 像素
- 地图 Tile：32×32 像素
- 建筑尺寸：多种（32×32, 64×64, 96×96）
- 色彩方案：以青绿为主色调，辅以金色（仙家气韵）和暗红（杀伐气）

### 7.2 开发阶段美术策略
- **初期**：使用简单几何图形和色块占位（矩形/圆形表示修士和建筑）
- **中期**：绘制基础像素角色和地形 Tile
- **后期**：完善动画帧（行走、打坐、战斗、突破特效）

## 八、已知风险与注意事项

1. **性能瓶颈**：大量修士同时运行 AI 可能导致卡顿，需限制活跃修士数量或使用时间切片
2. **平衡性**：境界修炼曲线需要反复调整，避免后期过于漫长或前期太快
3. **复杂度控制**：沙盒系统容易无限膨胀，每个阶段都要克制功能范围
4. **内容量**：随机事件和功法名称等文字内容需要一定量积累，可后续逐步补充
